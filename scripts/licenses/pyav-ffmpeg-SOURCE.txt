The build links the x264 and x265 encoder libraries (GPL version 2 or later); pyav-ffmpeg's patches/ffmpeg.patch moves
both off configure's GPL list, so the build does not pass --enable-gpl and reports "LGPL version 3 or later". Thanh Âm
Studio does not ship them: scripts/setup-runtime.ps1 replaces libx264-165-*.dll and libx265-*.dll in av.libs with
stubs of the same names built from scripts/encoder-stubs, which contain no x264 or x265 code and make opening those
two encoders fail. The FFmpeg libraries shipped here are therefore listed under the LGPL version 3 or later, whose
terms also require the GPL version 3 text.
