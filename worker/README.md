# CPU worker

Run `python -I -X utf8 worker/main.py`; send one UTF-8 JSON request, newline terminated, on stdin. One process handles one request; a `tts` request may carry `items` so the engine loads once for a batch of segments (each item reports its own `item` event). Stdout is JSONL protocol 1; third-party logging is redirected to stderr. The parent owns queue persistence, cancellation (terminate only this process) and partial file cleanup after a hard termination.

## Runtime

Use `scripts/setup-runtime.ps1` with uv available (no administrator rights). It builds `runtime/python` (private portable Python 3.11.18 plus the locked CPU inference closure, test suites pruned) and `runtime/ffmpeg` (pinned BtbN LGPL shared FFmpeg build, SHA-256 checked, with its license and source pointer). The installer bundles both; it never uses system Python, PATH or developer env vars in release builds. Models are NOT embedded. The desktop sets `THANHAM_FFMPEG`/`THANHAM_FFPROBE` to the bundled binaries.

`requirements-cpu.lock` intentionally installs with `--no-deps`: all inference dependencies are enumerated while upstream Gradio web UI dependencies are omitted. VieNeu code is pinned to commit `22dd2ef2a89bba24a77da6dbc84c75f7f4fda05b`. PyTorch `2.15.0+cpu` is the only package from a second index, pinned by URL and SHA-256 (uv refuses a wheel whose hash differs); Demucs 4.1.0 comes without its declared dependencies (only einops, julius and safetensors are needed for inference; no lameenc, dora or torchaudio). Torch's headers, import libraries and build tools are pruned. Only `separate` imports torch: `health` reports `torch_imported_by_engines` and is not ready when the engines pulled it in. Dependency licenses still need collection for a public installer; a runnable private environment alone is not release certification.

## Models

`models.json` pins each repository revision and every required file digest (LFS SHA-256 or Git blob SHA-1 for small files), sizes and license. Downloads stream over plain HTTP (Xet disabled) into `models/.download/<id>` and resume from the partial file after a kill or network error; disk space is checked first, progress is reported by bytes, network failures return `NETWORK`, and HF caches stay inside the models folder and are removed afterwards (no second copy). Each file is verified before atomic placement; `installed.json` is written only after all checks. Every inference verifies the model manifest again. `voices.json` contains public preset names/metadata only, from the pinned upstream Apache-2.0 asset; embeddings remain in the installed upstream package.

Model IDs: `vieneu-v3`, `whisper-small`, `whisper-turbo`, `diarization`, `htdemucs`. Pass `models/<id>` as `model_path`. VieNeu uses ONNX FP32, CPU, a single batch and no GPU dependencies. HF offline flags are set before engine imports. The pinned wrapper does not forward its codec directory, so a narrow constructor-scoped resolver maps only the known codec repository to our verified local codec folder. It is restored immediately after initialization. Unexpected model requests fail rather than fetching an unpinned model.

`htdemucs` (optional, user-started download) is the HTDemucs safetensors from `adefossez/HTDemucs` at `cbc8a9b`: code MIT, weights' license unclear upstream (trained with MusDB, research only). `separate` refuses a file whose metadata names another class than `demucs.htdemucs.HTDemucs` before building it (the SHA-256 pin is the real guard).

Fresh reference cloning is supported via `reference_path`; consent and asset access checks belong to the desktop boundary. Do not copy user voice references into source control.

## Audio recipe

Trim uses an exclusive end in milliseconds; null end means source duration. Fades clamp to trimmed duration. Gain range -60..24 dB. Gap is appended after each clip, including the final one, matching TTS subtitle recipe timing. Render streams each clip to 48 kHz mono PCM temporary chunks, then concatenates; this avoids a 500-input FFmpeg command and does not load all PCM in Python. Optional normalization targets -16 LUFS, -1.5 dBTP. Output WAV PCM24, MP3 192 kb/s, M4A (AAC) 192 kb/s, FLAC 24-bit or Opus 128 kb/s is finalized atomically. No input file is overwritten. On the subtitle timeline a `background_path` (a `separate` stem of the same media) is mixed in the last FFmpeg step: the dub is copied to both channels with `pan` (an `aformat` upmix would lower it by 3 dB), both start at sample 0 and are summed at 0 dB (`amix` `normalize=0`, `duration=longest`, no loop, stretch or fade), then, when normalizing, given one constant gain to -16 LUFS measured over the whole mix in a first pass (loudnorm's dynamic single pass would swell the bed between lines), and limited at 0.98 with latency compensation, so takes keep their places.

`separate` checks for 1.5 GB of free RAM, 2.5 GB of free commit (page file) and disk for twice the 24-bit stem plus 256 MB (`LOW_MEMORY`, `DISK_FULL`), then decodes the input once with FFmpeg to 44.1 kHz stereo and runs HTDemucs (8 threads, `shifts=0`) on 60 s windows that share 2 s, crossfaded linearly, so memory stays flat (60 s measured: 1.24 GB working set, 2.37 GB commit). The background is every source except `vocals`, streamed to a 24-bit FLAC. A cancelled job's partial file is removed by the desktop.

## Verification

`python -m unittest discover -s worker/tests -v` runs protocol, validation, checksum, missing-model and real FFmpeg render tests. Engine synthesis requires downloaded models and private dependencies; ordinary tests do not substitute fake successful audio. `.github/workflows/runtime.yml` runs them with the private runtime on every worker change; with `THANHAM_VIENEU_MODELS` set to an installed `vieneu-v3` folder, the clone preview is also compared with what a cloned synthesis enrolls. See `SMOKE.md` for measured runtime status.
